# Geosync
A deleted project by [@live-by-unix](https://github.com/live-by-unix), this is the only public copy of this game left. Hosted via Replit, so expect downtimes of a day or two every month or so. The files are in the [release](https://github.com/The-Restoration-Group/Geosync/releases) as they are too big and too many to post directly. Play it [here](https://folder-access-link--AVSH2.replit.app). This game has many key differences, most being improvements, however there are some bugs which are being worked on and should be fixed soon. - **NOTE:** This is pretty fatithful to the orginal copy apart from a few features being revamped/added and the addition of deco blocks and gamemodes. The game files are the EXACT same as the (now deleted) original and these descrpancies are caused by how Replit Agent builds websites based on files, so if you want to explore the orignal copy, download the files and try to figure out a way to run it directly.
